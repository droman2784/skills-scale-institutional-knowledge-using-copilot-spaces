# OctoAcme Project Management Docs

This guide is the central entry point for OctoAcme’s project management processes.

## Process overview

OctoAcme initiates work by clarifying the problem, stakeholders, goals, and success metrics. The team plans scope, milestones, dependencies, risks, and a prioritized backlog, then executes with regular standups, project board tracking, quality checks, and clear escalation paths. Releases include pre-release checks, smoke testing, and rollback readiness. Retrospectives turn lessons into action items that are tracked and followed up.
